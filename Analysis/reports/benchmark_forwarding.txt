3. ZERO-COPY FORWARDING AUDIT & CODE INTEGRITY REVIEW
--------------------------------------------------------------------------------
- Audit Question: Apakah path RX -> Forward -> TX melewati memcpy tersembunyi?
- Temuan Kode:
  1. Pada `asl-router-drivers-virtio`, penanganan descriptor menggunakan
     `DescriptorRing<RxDesc16, 16>` di mana buffer dialokasikan statis pada
     `asl-router-netbuf` buffer pool.
  2. Saat forwarding IP murni (L2/L3 transit tanpa perubahan payload), buffer
     descriptor langsung diteruskan dari ring RX antarmuka masuk ke ring TX antarmuka
     keluar (`netbuf-reuse`).
  3. Pengecualian Kejujuran: Saat SNAT/DNAT aktif, header IPv4 (20 byte) dan header
     L4 (8 byte ICMP/UDP/TCP) dimodifikasi in-place untuk penulisan ulang IP/Port
     dan rekalkulasi checksum RFC 1071 1's complement. Modifikasi header in-place
     ini BUKAN memcpy payload paket, sehingga sifat zero-copy payload tetap terjaga.
  4. Seluruh operasi berada dalam heapless `#![no_std]` tanpa `alloc` runtime.
