Akun

Aksi tulis akun khusus admin dan kernel menjawab 403 insufficient_role; tombol tulis di sini hanya disembunyikan sebagai pengalaman pakai, bukan sebagai penjaga.

Akun

3—16 karakter: huruf kecil, angka, "-", "_", ".". Tabel kredensial kernel menampung 4 akun.

Kata sandi

10—64 karakter. Sandi hanya turun menjadi PBKDF2-HMAC-SHA256 di lapisan server; ia tidak pernah dapat dibaca kembali, sehingga mengubah akun selalu menuntut sandi baru.

Ubah akun menuntut kata sandi baru: lapisan server tidak pernah mengeluarkan garam, hash, maupun sandi lama, jadi tidak ada nilai yang bisa disalin kembali.

Balasan status di bawah adalah kutipan kernel: set dan del berjanji persist=queued lalu verdict RJCFG01 dibaca ulang, sedangkan revoke hanya membalas jumlah sesi yang dicabut dan ikut mematikan sesi ini.
